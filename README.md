# Student Enrollment Analytics Dashboard

This Power BI project explores a synthetic dataset of student enrollment characteristics across U.S. states. The goal is to analyze how factors such as **years enrolled**, **student age**, **family income**, **public school background**, and **religious denomination** may relate to one another.

## 📊 Overview

The report includes:
- **Visual breakdown of enrollment years** by public school background
- **Average student age** in relation to number of years enrolled
- **Family income averages** by Christian denomination
- **Summary KPIs** including average student age and family income
- **Interactive filters** (e.g., denomination slicer)

## 📌 Key Insights

- Students with more years enrolled are generally older, suggesting retention over time.
- Baptist families exhibit a wide income range, with a noticeable skew toward higher income brackets.
- Public school background does not show a strong difference in years enrolled.

## 🛠️ Tools Used

- Power BI Desktop
- Custom visuals (column charts, bar charts, KPIs)
- Data filtering and formatting
- Text box annotations for insights

## 📁 Data

The data used is **synthetic** and was generated for the purpose of this demonstration. No personally identifiable or real-world data is included.

## 💡 Purpose

This dashboard was created as part of a personal portfolio to showcase:
- Comfort working with categorical and numeric data
- Clear, readable visuals with labeling and KPI usage
- Ability to interpret and communicate insights from data

## 📌 Notes

This is not an advanced statistical or predictive analysis—it's an exploratory dashboard designed to show competence with:
- Layout and design
- DAX-based aggregation (e.g., averages)
- Insight communication
